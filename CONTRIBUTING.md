# Contributing

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Make changes and run tests: `npm test`
4. Push and open a Pull Request

## Code Style

- Use 2-space indentation
- Follow existing patterns in the codebase
- Test coverage for new features

## Pull Request Process

1. Ensure tests pass and lint is clean
2. Update documentation if adding or changing features
3. The PR will be reviewed by maintainers

## Code of Conduct

Please note this project has a [Code of Conduct](CODE_OF_CONDUCT.md). By participating you agree to its terms.
